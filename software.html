Los programas y las instrucciones

Software.

La parte lógica. Las instrucciones que convierten un conjunto de piezas en una herramienta.

Software de sistema

El sistema operativo administra el procesador, la memoria, los archivos y los dispositivos. Además, ofrece un entorno para ejecutar aplicaciones e interactuar con el equipo. Windows, macOS y las distribuciones GNU/Linux son ejemplos de sistemas operativos para computadoras.

Los controladores permiten que el sistema operativo se comunique con dispositivos específicos, como una impresora o una tarjeta de red. Las utilidades de sistema ayudan a realizar tareas de mantenimiento, como gestionar el almacenamiento o crear copias de seguridad.

Software de aplicación

Son los programas que utilizamos para actividades concretas. Los procesadores de texto permiten redactar documentos; las hojas de cálculo organizan datos y realizan operaciones; los navegadores permiten consultar páginas web.

También pertenecen a esta categoría los editores de imágenes, reproductores multimedia, videojuegos y aplicaciones educativas. Algunos se instalan en el equipo y otros se utilizan desde un navegador. Una aplicación web puede requerir conexión a internet para ciertas funciones.

Software de programación

Reúne herramientas para crear otros programas. Los editores de código permiten escribir instrucciones; los compiladores e intérpretes intervienen en la traducción o ejecución del código; los depuradores ayudan a localizar errores.

Un entorno de desarrollo integrado (IDE) combina varias de estas herramientas. Python, Java y C++ son ejemplos de lenguajes de programación. HTML es un lenguaje de marcado que organiza el contenido de páginas web, mientras que CSS define su presentación.

Licencias y uso responsable

La licencia establece cómo se puede utilizar y distribuir un programa. El software propietario puede restringir su modificación y redistribución. El software libre concede libertades para usar, estudiar, modificar y compartir el programa según su licencia. Que un programa sea gratuito no significa necesariamente que sea software libre.

Descarga programas de fuentes oficiales, mantén el sistema y las aplicaciones actualizados y revisa los permisos que solicitan. Las actualizaciones pueden corregir errores y vulnerabilidades. Conserva copias de seguridad de tus archivos importantes.

Hardware y software en una misma tarea

Cuando reproduces una canción, una aplicación lee el archivo de audio, el sistema operativo coordina los recursos y el hardware procesa y reproduce el sonido. El programa aporta las instrucciones; los componentes físicos ejecutan las operaciones.
