# La computadora

Guía visual educativa en español sobre los elementos de una computadora. Sitio estático para PC, sin dependencias de terceros ni conexión requerida después de descargar los archivos.

## Páginas

- `index.html`: elementos de la computadora y ciclo de entrada, procesamiento, salida y almacenamiento.
- `hardware.html`: componentes físicos del equipo.
- `software.html`: sistemas operativos, aplicaciones y herramientas de programación.

Abre `index.html` en un navegador o publica este directorio con GitHub Pages.

## Recursos

Las fotografías se descargan y conservan en `assets/`, por lo que el sitio no depende de un servicio remoto para mostrarlas. Créditos y enlaces a los originales se encuentran bajo cada foto. Fotografías de Unsplash. Fira Sans y Fira Sans Condensed se sirven localmente bajo SIL Open Font License 1.1; consulta `assets/OFL-Fira-Sans.txt`.
